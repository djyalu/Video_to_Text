# Video_to_Text 구현방안

## 1. 목적
ebook 화면 넘김 영상에서 페이지별 텍스트를 안정적으로 추출하고, 결과물을 `Markdown/HTML/PDF`로 일괄 생성하는 CLI 파이프라인을 제공한다.

## 2. 현재 구현 상태 (2026-02-23 기준)

### 2.1 완료된 핵심 기능
- CLI 실행 진입점 구현 (`python -m video_to_text`)
- 페이지 전환 감지 기반 프레임 추출
  - 상태 머신(`stable -> transition -> stable`)
  - 샘플링 FPS 기반 분석
  - 선명도 기반 대표 프레임 선택
  - pHash 기반 유사 페이지 중복 제거
- OCR 엔진 추상화 및 백엔드 지원
  - `auto`, `paddle`, `tesseract`
  - 페이지별 단어 bbox/신뢰도 수집
- 텍스트 정규화
  - 유니코드 NFKC, 공백/개행 정리, 하이픈 줄바꿈 병합
- 산출물 생성
  - `pages/*.jpg`, `ocr/*.json`, `book.md`, `book.html`, `book.pdf`, `report.json`

### 2.2 구현 파일 매핑
- CLI/인자 처리: `video_to_text/cli.py`
- 파이프라인 오케스트레이션: `video_to_text/pipeline.py`
- 영상 처리/프레임 추출: `video_to_text/video_processing.py`
- OCR 엔진: `video_to_text/ocr_engine.py`
- 출력 포맷 생성: `video_to_text/exporters.py`
- 데이터 모델: `video_to_text/models.py`

## 3. 목표 품질 지표
- 페이지 누락률: 3% 이하
- 중복 페이지율: 2% 이하
- OCR 평균 신뢰도: 0.80 이상(고해상도 입력 기준)
- 처리 실패율: 1% 이하(입력 파일 유효성 제외)

## 4. 단계별 구현 방안

### Phase 1. 안정화 (단기)
1. 예외/오류 메시지 표준화
- 입력 파일 없음, OCR 미설치, 프레임 미추출 상황에 대해 일관된 메시지와 종료코드 유지.

2. 리포트 확장
- `report.json`에 처리시간, 엔진명, 추출 파라미터, 실패 페이지 수 필드 추가.

3. 문서화 보강
- 임계값 튜닝 가이드(누락/중복/지연 케이스)와 샘플 명령어를 표 형태로 정리.

### Phase 2. 정확도 개선 (중기)
1. 레이아웃 인지 OCR 후처리
- 문단/헤더/목록 추정 규칙 추가.
- 줄 단위 결합 로직 개선(번호/기호/각주 보존).

2. 페이지 경계 감지 강화
- 단순 평균 차이(diff) 외에 SSIM 또는 히스토그램 거리 보조 신호 도입.
- 애니메이션/스크롤 전환 영상 대응력 향상.

3. 품질 필터링 개선
- 저품질 페이지 재시도(인접 프레임 재탐색).
- OCR confidence 하한 미달 페이지 표시/재처리 옵션 제공.

### Phase 3. 운영성 강화 (중장기)
1. 배치 처리
- 다중 입력 파일 처리(`--input-dir`) 및 결과 구조 표준화.

2. 재현성/성능
- 동일 입력-동일 파라미터에서 결정적 결과 보장.
- 병렬 OCR 옵션(페이지 단위 워커)으로 처리 시간 단축.

3. 배포
- `pipx`/wheel 배포 또는 단일 실행 패키지(PyInstaller) 제공.

## 5. 테스트 전략

### 5.1 자동 테스트
- 단위 테스트
  - `normalize_text` 케이스(공백/개행/하이픈 병합)
  - OCR 엔진 선택 로직(`auto` fallback)
- 통합 테스트
  - 짧은 샘플 영상으로 페이지 수/파일 생성/리포트 검증
- 회귀 테스트
  - 파라미터 세트별 기준 결과(JSON snapshot) 비교

### 5.2 수동 검증 체크리스트
- 빠른 넘김/느린 넘김/블러 구간 포함 영상 각각 검증
- 한국어+영어 혼합 텍스트 OCR 품질 확인
- `--no-pdf`, `--no-html`, `--no-markdown` 옵션 조합 검증

## 6. 우선순위 백로그
- P0
  - 테스트 코드 기본 세트 구축
  - `report.json` 메타데이터 확장
- P1
  - 페이지 감지 보조 신호(SSIM/히스토그램) 추가
  - OCR 후처리(문단 결합 규칙) 개선
- P2
  - 배치 처리 및 병렬 OCR
  - 배포 자동화

## 7. 리스크 및 대응
- OCR 엔진 외부 의존성 설치 실패
  - 대응: `--list-engines` 사전 점검, 설치 가이드 강화
- 영상 특성(자막/애니메이션)으로 오탐 증가
  - 대응: 보조 신호 + 파라미터 preset 제공
- PDF 폰트 문제(한글)
  - 대응: 한글 폰트 등록 옵션/가이드 제공
